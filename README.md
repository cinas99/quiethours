# Quiet Hours Studio – strona

Strona studia i polityki prywatności aplikacji, hostowana za darmo na GitHub Pages.

- Adres: https://cinas99.github.io/quiethours/
- Polityki prywatności: `privacy/<aplikacja>.html` (wersja angielska i polska na jednej stronie)

Zmiany: edytuj `CONFIG` i `APPS` w `build.py`, uruchom `python3 build.py`, zatwierdź wygenerowane pliki.
